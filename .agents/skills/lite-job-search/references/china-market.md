# 中国市场检索

## 发现顺序

1. 检查已知企业招聘域名和 ATS 租户缓存。
2. 从 Gank Interview、牛客招聘日程、牛企直聘、实习僧、应届生求职网、国聘等公开页面发现线索。
3. 优先读取线索页已经给出的公告链接和投递链接。
4. 过滤聚合平台自身链接，再检索“公司名 + 招聘”。
5. 验证企业主体、招聘语义和当前岗位列表。

浪浪网申不作为默认信息源。

## 百度浏览器检索

使用可见、正常的 Chrome 会话搜索：

```text
"公司名" 招聘官网
"公司名" 校园招聘
"公司名" 招聘职位
"公司名" 实习 投递
```

忽略广告、新闻、内容站和百度内部搜索跳转。优先选择品牌自有域名下的招聘页面；不要把公司主业务首页误认为招聘入口。

若没有官方招聘站，可保留经过公司主体匹配的 ATS 企业页。BOSS、智联、猎聘普通企业页只能作为降级线索或最后入口，必须明确标记，不能冒充官方域名。

## 官方验证

企业自有域名至少满足：

- 域名与企业品牌、已知主域或注册表相符；
- 页面出现公司名称、Logo、版权主体、JSON-LD 或站点名称等身份信号；
- 页面出现招聘、职位、加入我们、校园招聘、Careers、Jobs 等招聘语义。

ATS 必须同时匹配平台指纹与公司租户。支持 Moka、北森/Hotjob、飞书招聘、智联招聘系统、Moseeker、Workday、Greenhouse、SmartRecruiters 等已抽取 provider。

## 链接角色

- 聚合、高校、政府、媒体、公众号文章：`sourceUrl`。
- 长期招聘门户：`companyCareerHomeUrl`。
- 特定届次或招聘活动页：`campaignLandingUrl`。
- 多岗位列表：`jobListUrl`。
- 单岗位详情：`jobDetailUrl`。
- 直接申请动作：`applyUrl`。

只有身份确认且页面可访问，并存在岗位列表或申请动作时，才显示“查看岗位并投递”。
