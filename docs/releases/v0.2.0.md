# LJS v0.2.0

状态：Release candidate

v0.2.0 将生产重心从“反复全网搜索公司招聘官网”迁移到“招聘入口知识库与增量监控
网络”。该版本保留现有 Provider Contract、Verification Engine 和 CLI 语义。

## 新增

- `SourceEndpoint`：可重复监控的官方招聘入口、ATS、JSON、Sitemap 或官方社交入口。
- `FetchObservation`：一次真实访问的状态、哈希、页面角色、岗位数量、失败原因和证据。
- `JobRevision`：岗位首次发现、变化、再次出现、关闭和重新开放的版本事实。
- `MonitorPolicy`：四类队列、检查频率、优先级及浏览器/搜索权限。
- 已知招聘入口 Worker：直接检查 `VERIFIED` 门户，内容未变化时跳过重复解析。
- 中国 ATS 覆盖审计：按当前 SQLite 实际覆盖率排序 Adapter 投资优先级。
- 本地看板监控网络指标和 `/api/monitoring-network` 审计接口。

## 调度变化

- `PORTAL_MONITOR`：已核验入口的日常增量检查。
- `PORTAL_RECOVERY`：失效、跳转或解析异常的已知入口恢复。
- `MARKET_DISCOVERY`：新公司和未知入口的低频搜索补充。
- `REVIEW_FEEDBACK`：人工审核和用户失效反馈触发的复检。

搜索引擎 Circuit 只会延后 `MARKET_DISCOVERY`。已知入口监控不依赖搜索引擎，浏览器仍是
兜底通道。访问受阻不会被写成“无岗位”。

## 数据与兼容性

- 新增幂等迁移 `013-monitoring-network.sql`。
- 已有 `VERIFIED`、`REVIEW`、`BLOCKED` 官方门户会回填为监控端点。
- 第三方平台记录仍不能进入学生正式投递表。
- 单次失败和单次岗位缺失不会关闭历史岗位。

## 验证声明

自动化测试和数据库副本迁移用于验证代码与兼容性，不等同于七日真实稳定性结果。七日
Canary 应按 `docs/runbooks/v0.2-seven-day-canary.md` 独立执行并保留真实报告。
