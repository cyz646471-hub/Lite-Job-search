# LJS PRD 变更记录

## 2026-07-29：固化 v0.2 招聘入口监控网络

- 新增招聘入口知识库与增量监控架构说明和 ADR。
- 新增 `SourceEndpoint`、`FetchObservation`、`JobRevision`、`MonitorPolicy`。
- 将任务分为入口监控、入口恢复、市场发现和审核反馈四条队列。
- 搜索熔断只隔离市场发现，不再阻塞已确认入口检查。
- 增加国内 ATS 实际覆盖审计、看板监控指标和七日 Canary 手册。
- 该变更不修改 PRD 基线；它是当前 PRD 下的 v0.2 工程实施版本。
