## 变更规则

1. 不直接覆盖或静默改写已登记的 V1.0 基线。
2. 对话中出现与基线不一致的新要求时，先指出冲突、影响范围和建议处理方式。
3. 只有在产品负责人明确确认后，才能：
   - 新建下一版本 PRD；
   - 增加决策记录；
   - 修改路线图优先级或验收标准。
4. 已确认变更应保留日期、确认内容、影响模块和迁移说明。
5. 原始 V1.0 文件持续保留，用于差异比较与回滚。
